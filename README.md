### 🚀 Featured Projects

#### 🔐 [Shadow Room — E2E Encrypted Chat](https://github.com/gurjotsingh1774/Shadow-Room)
A fully completed end-to-end encrypted messaging platform supporting one-to-one and group chats, built from the relay up.
- Go WebSocket hub with **Redis-backed queuing** for offline delivery
- **Ticket-based ECDSA authentication**
- **Double Ratchet** algorithm for perfect forward secrecy in 1-to-1 chats
- **Sender Keys** for secure group scaling

`Go` `WebSockets` `React.js` `Protocol Buffers` `PostgreSQL` `Redis`

[📦 Repository](https://github.com/gurjotsingh1774/Shadow-Room) · [🌐 Live Site](https://shadow-room.gurjot.codes/)

#### 🎟️ [Secure Token Allocation Platform](https://github.com/gurjotsingh1774/secure-token-allocation)
A real-time, app-less digital queue and token allocation platform.
- Instant pass generation
- Live **Server-Sent Events (SSE)** position streaming
- **Cryptographic QR verification** with HMAC signatures
- Dynamic administrative vendor management

`Go` `Gin` `React.js` `TypeScript` `PostgreSQL` `SSE` `IndexedDB`

[📦 Repository](https://github.com/gurjotsingh1774/secure-token-allocation) · [🌐 Live Site](https://secure-token-alloc.gurjot.codes/)
